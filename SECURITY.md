# Security policy

To report a vulnerability in Roaring Lions, use GitHub's private vulnerability reporting for this repository:
<https://github.com/ilan-pinto/roaring-lions/security/advisories/new>

Please do not open a public issue or pull request for a vulnerability. Reports are read by the maintainer, who will
acknowledge them and tell you what happens next.

The same pointer is served by the game's site at `/.well-known/security.txt`.

This is for security problems. Requests about your personal data (a copy, an export, a deletion or a correction) go
through the private form at `/privacy/request` on the game's site instead.
